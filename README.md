# Merge Sort — C++

An implementation of the **Merge Sort** algorithm in C++. This project demonstrates divide-and-conquer sorting, recursion, temporary arrays, and merging sorted subarrays.

## Concepts
- Divide-and-conquer
- Recursive functions
- Array manipulation
- Merging sorted sections
- Time complexity: **O(n log n)**

## Run
Compile and run `MergeSort_0227.cpp` with any C++ compiler supporting standard C++ syntax.
